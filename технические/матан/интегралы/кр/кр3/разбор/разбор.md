## №4

Тут подынтегральное выражение будет являться производной какой-то функции по а. Вам могут дать такую функцию, а может и придётся брать интеграл по $a$ от исходной функции.

**Пример:**
$\int_0^{+\infty}g(x, a)dx$, $f'_a(x, a) = g(x, a)$
Тогда $\int_0^{+\infty}g(x, a)dx = \int_0^{+\infty}f'_a(x, a)dx = (\int_0^{+\infty}f(x, a)dx)'_a$
_Это должно хорошо считаться, когда посчитаете необходимо будет проверить ещё условия:_

1. $f(x, a)$ непрерывна по $х$ при любом фиксированном $a$
2. $f'_a(x,a)$ непрерывна и по $х$, и $a$ одновременно
3. $\int_0^{+\infty}f(x, a)dx$ сходится
4. $\int_0^{+\infty}f'_a(x, a)dx$ сходится _(локально)_ равномерно
