## Тренировочная задача 1

Задано преобразование

```text
S(  X1 || X2 || X3 ) -> F(X1 + X2) || F(X2) + F(X3) || X3 + X1 .
```

И всё что известно, что F — биективная функция.
Найдите обратное преобразование `S^{-1}` или докажите, что такого нет.

Для определенности считайте, что `X1, X2, X3` из `{0,1,... p - 1}`, все вычисления идут по модулю `p`.

---

### ШАГ 1: попытаться обратить преобразование

```text
S(  X1 || X2 || X3 ) -> A || B || C
A = F(X1 + X2)
B = F(X2) + F(X3)
C = X3 + X1
```

Пробуем `X1, X2, X3` выразить из `A, B, C`

```text
X1 + X3 = C
X1 + X2 = F^{-1}(A)
```

Отсюда можно выразить

```text
X3 - X2 = C - F^{-1}(A)
```

### ШАГ 2: натыкаемся на проблемы

Видим, что нет какого-то адекватного способа обратить B, пробуем это использовать чтобы доказать что преобразование может и не быть биективным.
В качестве доказательства у нас должен выступить явный пример.

### ШАГ 3: строим пример

`B = F(X2) + F(X3)` сложно контролировать т.к. выражение сразу от двух переменных и говорить о биективности или нет сложно. Переведем к функции одной переменной. Способ для этого не единственный, но например сделаем так:

```text
B = F(X2) + F(X3)
  = F(X2) + F(X2 + (X3 - X2))
  = {мы хотим использовать функцию от одной переменной: X2 и используем то что уже нашли ранее на шаге 1}
  = F(X2) + F(X2 + (C - F^{-1}(A)) )
  = {видим что (C - F^{-1}(A)) вообще не зависит от B, т.е. при вычислении B это воспринимается просто как константа}
  = F(X2) + F(X2 + Const )
```

Если при этом для любой константы `Const` по `B` можно вычислить `X2`, то действительно преобразование `S` обратимо. Но довольно сомнительное утверждение. Опровергнем его примером.

### ШАГ 4: строим конкретный пример

Можете взять конкретный пример `F(X) = x^2 mod p`, `p=5` и показать что

```text
F(1)+F(1+1) = 0 = F(3)+F(3+1)
```

найти когда `const=1`, т.е.

```text
X3-X2 = 1
```

Это например

```text
S(312)=S(134)=100
```

Итого: доказано, что даже если F-биекция, то S- может быть не биективной функцией. Т.е. успешно доказали что `S^{-1}`, в общем случае, не существует

## Тренировочная задача 2

**Тренировочная задача 2.**
Возьмите какое-то множество `A` предложите иволютивную функцию `t: A -> A`.
На основании функции `t` предложите `t`-инволютивную функцию `s` без неподвижных точек.

### ШАГ 0: вспомнить определения

функция `t` инволютивна если `t(t(x))=x` для любого `x` из `A`.
функция `s` является `t`-инволютивной если `s(t(s(x))) = t(x)`

### ШАГ 1: ввести A и придумать t

Пускай, например, `A` это числа `{1,2,3,4,5,6}`;
Всё как может действовать `t` это парочками менять числа между собой, или число оставлять самим собой.
Приведем пример когда есть и то и другое:

```text
t: (1,3,2,5,4,6)
```

{читать так:

```text
(1,2,3,4,5,6)
перешло в
(1,3,2,5,4,6)
```

и читать по столбцам, скажем 3 переходит в 2, а 6 в 6
}

### ШАГ 2: составление закономерностей

пусть на вход пришло некоторое число `a` из `A` такое, что `s(a)=1`.

```text
тогда t(a) = s(t(s(a))) = s(t(1)) = s(1).
```

Аналогично пройдемся по всем

```text
s(a)=1
s(b)=2
s(c)=3
s(d)=4
s(e)=5
s(f)=6
```

и

```text
s(1)=t(a)
s(2)=t(c)
s(3)=t(b)
s(4)=t(e)
s(5)=t(d)
s(6)=t(f)
```

### ШАГ 3: начинаем предположения

мы не хотим чтоб сложилась ситуация где `s(x)=x` т.к. это неподвижная точка, в остальном мы довольно свободны в предположениях.

Пусть `s(1) = 2`, тогда `b=1` *(т.к. `s(b)=2`)* и `a=3` *(т.к. `2=s(1)=t(c)=t(3)`)*, раз так, то `s(3)=1` *(т.к. `s(3)=t(b)=t(1)=1`)*

На этом выводы которые удавалось однозначно сделать закончились.

### ШАГ 4: продолжаем предположения

Пускай, например `s(2)=6`.
Тогда `s(6)=3` *(попробуйте обосновать самостоятельно)*

Значит образовался числовой цикл

```text
1-> 2 -> 6 -> 3 -> 1
```

Оставшиеся преобразования определим из избегания неподвижных точек:

```text
s(4)=5
s(5)=4.
```

Итого `s` имеет вид `(2,6,1,5,4,3)`. Неподвижных точек нет.
