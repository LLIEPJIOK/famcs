## Темы

1. моделирование дсв методом макларена-марсальи.
2. моделирование методом инверсии двух случайных величин (Пуассона, Бернулли, геометрическое, ...).

## Задачи

**Задача 1**
Смоделировать случайную величину с заданным законом распределения: $P(X=0) = \frac{1}{4}$ и $P(X=1) = \frac{3}{4}$.
* **Метод:** Макларена-Марсальи
* **Параметры:** $U = 0.2$, $V = 0.6$

**Задача 2**
Смоделировать биномиальное распределение $B(n, p)$ при $n = 3$ и $p = \frac{1}{4}$.
* **Метод:** Макларена-Марсальи
* **Параметры:** $U_1 = 0.1$, $U_2 = 0.3$, $U_3 = 0.5$

**Задача 3**
Смоделировать случайную величину для геометрического распределения с вероятностью успеха $p = \frac{1}{4}$ (до первого успеха).
* **Метод:** Макларена-Марсальи
* **Параметры:** $U = 0.4$, $V = 0.6$

**Задача 4**
Смоделировать равномерное распределение случайной величины $X$ на отрезке $[2, 5]$.
* **Метод:** Макларена-Марсальи
* **Параметры:** $U = 0.6$, $V = 0.8$

**Задача 5**
Для распределения из Задачи 2 найти математическое ожидание и/или дисперсию.
