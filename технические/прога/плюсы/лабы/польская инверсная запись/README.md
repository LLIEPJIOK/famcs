# Польская инверсная запись

Польская инверсная запись (ПИЗ) — это способ записи арифметических выражений, при котором операторы следуют за операндами. Например, выражение "3 + 4" в ПИЗ будет записано как "3 4 +". Этот формат позволяет легко вычислять выражения с помощью стека, так как не требует скобок для определения порядка операций.
