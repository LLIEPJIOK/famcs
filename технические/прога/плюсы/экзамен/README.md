## Задачи

### На 9-10

Нужно было составить список абонентов телефонной станции и упорядочить его в алфавитном порядке. Абоненты записаны в текстовом файле, один абонент в каждой строке и записаны семизначный номер телефона, фамилия, имя, отчество через пробел для каждого абонента. У абонентов может быть несколько номеров телефона и в таком случае номер записан в другой строке под тем же ФИО человека и необязательно, что эти строки идут подряд. Также нужно написать функции для вывода списка в консоль, поиска абонента по номеру телефона, имени, фамилии, отчеству и функцию удаления всего списка.
