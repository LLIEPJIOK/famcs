Материалы для лабораторной работы "Работа с Unix-подобными операционными системами"
Для выполнения данной работы вам потребуется либо непосредственно установленная UNIX-подобная система на вашем компьютере, либо виртуальная машина с системой семейства UNIX, либо (для пользователей Windows) установленная подсистема Windows для Linux (WSL). Большинство, вероятно, пользуется Windows на своих компьютерах, и им проще будет установить себе WSL либо виртуальную машину.

WSL (Windows Subsystem for Linux) - появившийся в Windows 10 компонент совместимости, позволяющий запускать приложения Linux. Руководство по установке и использованию WSL можно найти здесь:
