\begin{frame}
\frametitle{Класс NP-полных задач  поиска оптимальной сенсорной
конфигурации  }

\vspace{2mm} Для исследуемого  \textcolor{blue} {класса NP-полных
задач } применение cтратегий \textcolor{blue} {полного перебора }
вариантов:

$$C_m^1=m,\,C_m^2=\frac{m(m-1)}{2},\ldots,\,C_m^k=\frac{m!}{k!(m-k)!} $$
\vspace{2mm} размещения сенсоров в узлах сети (сенсорных
конфигураций) из $ m=|I| $ узлов сети для поиска \textcolor{blue}
{оптимального решения } задачи SLP \vspace{2mm} потребует
\textcolor{blue} {огромных вычислительных затрат}.
% даже для сетей относительно малой размерности.

\end{frame}
